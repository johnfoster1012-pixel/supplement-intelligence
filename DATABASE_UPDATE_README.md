# Historical database update notice

The original Phase 1 Ashwagandha, Berberine, and NAC database experiment has been retired.

The associated study Markdown files, PDFs, and standalone schema files were removed from the active branch because the original citation-to-topic and citation-to-product mappings did not consistently meet the project's current verification standard.

## Current approach

Research is now rebuilt ingredient-first using:
- `ingredient-evidence.json`
- `docs/EVIDENCE_METHOD.md`
- primary or authoritative sources
- explicit separation between ingredient evidence and finished-product evidence

The active ingredient library is available at:

https://supplement-intelligence.com/ingredients

The current research-status page is:

https://supplement-intelligence.com/references

Do not restore the retired database files without a fresh source-by-source verification.
