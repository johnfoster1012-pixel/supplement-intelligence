# Distribution and citation policy

Supplement Intelligence uses external platforms for legitimate educational distribution, not to manufacture apparent consensus.

## Canonical rule
The canonical source is the verified page on supplement-intelligence.com.

## Requirements before distribution
- current product label/formulation verified
- claims supported by appropriate sources
- citations checked
- affiliate or material relationship disclosed where relevant
- canonical URL set
- no unsupported claims repeated across platforms

## Preferred order
1. Publish the verified canonical page.
2. Share an educational summary on relevant channels.
3. Use Medium import only when canonical attribution is preserved.
4. Maintain GitHub as a transparent machine-readable mirror of current verified data.
5. Use community platforms only when the contribution is genuinely useful and follows community rules.
