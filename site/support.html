Support

Supplement Intelligence provides verification-first supplement ingredient evidence and product formulation research.

Report a data issue

If you identify a formulation, citation, broken link, or evidence-summary issue, please open an issue in the public GitHub repository at Supplement Intelligence Issues. Include the page URL and the source that appears to conflict with the published record.

Plugin support

The Supplement Intelligence ChatGPT plugin is read-only. It searches the same reviewed evidence and current formulation data published by this project. It does not provide personalized diagnosis, treatment, or dosage recommendations.

For data-quality questions, use the GitHub issue tracker so the correction can be reviewed transparently.
