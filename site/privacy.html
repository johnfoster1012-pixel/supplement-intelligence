Privacy Policy

Effective date: October 2, 2026

Supplement Intelligence website

Supplement Intelligence publishes public supplement formulation and ingredient-evidence information. The core research pages and public API do not require a user account.

ChatGPT plugin and MCP server

The Supplement Intelligence MCP server is read-only. Its tools receive only the task-specific parameters needed for a request, such as an ingredient slug, product slug, or search query. The plugin does not request medical records, diagnoses, prescriptions, laboratory results, contact details, or other protected health information.

The MCP tools retrieve public project data and return research/formulation results to ChatGPT. No user profile or persistent research history is created by these tools.

Infrastructure logs

Hosting and infrastructure providers may process routine technical request information needed to operate and secure the service, such as network and request metadata, under their own service terms and privacy practices. Supplement Intelligence does not use the MCP tools to build advertising profiles from user queries.

External links

Pages may link to research sources, GitHub, and manufacturer websites. Those destinations have their own privacy practices.

Changes

This policy may be updated if the service later adds accounts, saved research, authentication, or other features that process additional user information. Material changes will be reflected on this page.

Contact

Data-quality and privacy questions can be submitted through the public GitHub issue tracker.
