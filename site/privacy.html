Privacy Policy

Effective date: October 2, 2026

Supplement Intelligence provides public, read-only supplement research and product-formulation information. The public ChatGPT plugin and MCP tools do not require an account and are not designed to collect personal health information.

Information processed

When a user invokes a plugin tool, the MCP service processes the narrow search term, ingredient slug, or product slug needed to answer that request. The service does not request names, email addresses, medical records, diagnoses, medication lists, payment information, government identifiers, passwords, or authentication secrets.

Purpose

Tool inputs are used only to retrieve the requested Supplement Intelligence research or formulation record and return it to the user.

Recipients

The service uses Cloudflare to host the MCP endpoint and GitHub to host the public source data used by the MCP service. Requests may therefore be processed through those infrastructure providers under their applicable terms and privacy practices.

Retention

Supplement Intelligence does not maintain a user-profile database for the public read-only plugin. Standard infrastructure providers may retain operational logs according to their own service configurations and policies.

User controls

Users can stop using or uninstall the plugin at any time. Because the public plugin does not create user accounts or profiles, there is no plugin-specific profile data to edit or delete.

Sensitive information

Do not submit protected health information, payment-card information, government identifiers, passwords, API keys, or other restricted data to the plugin.

Contact

Questions about this policy can be submitted through the support page.
